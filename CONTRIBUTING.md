# Contributing to Eclipse

Thanks for your interest in Eclipse.

## Current focus

The first development focus is the ECL sentence-based language. Keep syntax explicit and predictable. Do not silently reinterpret unknown commands.

## Before submitting changes

1. Keep changes focused and document new ECL sentence forms in LANGUAGE-GUIDE.md.
2. Add automated tests for parser and interpreter behavior.
3. Run npm test with Node.js 20 or newer.
4. Update docs/ROADMAP.md only when a milestone's status genuinely changes.

## Feature status

Do not describe planned functionality as implemented. The current scene preview is a small language demonstration, not a production renderer or runtime.
